# QCAUSE2026-1400-V.2
QCAUSE2026-1400 (Quality Control Analisis Usaha SE2026 BPS Provinsi Riau) merupakan shiny application yang dibangun untuk melakukan penjaminan kualitas hasil SE2026 di BPS Provinsi Riau dari sisi coverage, ketepatan Klasifikasi Baku Lapangan Usaha (KBLI), dan kewajaran data beberapa indikator ekonomi.
